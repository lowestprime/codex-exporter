# Codex Exporter v0.5.0

Large exports could exhaust disk space after expensive compression because source
copies and raw multipart segments coexisted with the snapshot, rendered files and
compressed candidates. Failed archive jobs also left loose render outputs for a
later retry to accumulate. This release makes default archived exports private
transactions and removes those redundant staging allocations.

## Storage and bounded archives

- Borrow the verified immutable snapshot for archive-only native JSONL members;
  retain source copies only when loose outputs are explicitly requested.
- Render in owned private workspaces and publish verified archives only. Clean
  failed job staging without deleting live rollouts, databases or prior exports.
- Add `--work-dir` and persisted archive `work_dir`, measured allocation checks,
  volume-specific disk-full errors and progressive retirement of owned candidates.
- Compress exact ranges directly through the selected encoder, assemble from
  already-compressed streams, and fully verify the final bounded archive set.
- Preserve a single ordinary ZIP when it fits, including near-cap cases. Improve
  modest multipart packing with bounded exact search and disclose its scope.
- Match ZIP, multipart and segment prefixes to the resolved export stem; reserve
  pending batch names so private staging cannot hide collisions.
- Keep LZMA/9/256m/64/19 preferences, the hard 512,000,000-byte ceiling and inherited
  Windows output permissions. No silent compression-method downgrade is added.

## Listings and Markdown

- Add multi-column sorting with individual ascending/descending directions,
  consistent aliases and original selector numbers retained after sorting.
- Page long terminal listings with terminal-height limits, wrapping, resize-aware
  navigation, Enter/Space/Page keys, arrows, Home/End and Q. Files/pipes/JSON remain
  complete and noninteractive; the browser keeps its selection controls.
- Index plain JSONL user-turn listings without disk staging, then independently
  verify the fixed prefix and disclose any deferred unparseable tail.
- Classify complete service goal/page/context envelopes as preserved context rather
  than human turn anchors. Respect distinct native turn IDs during deduplication.
- Add source-time Markdown labels by default, configurable by invocation or saved
  preference. Support local/UTC/source/fixed-offset/IANA zones and event-date DST;
  never fabricate timestamps or alter native JSONL.
- Show versioned, documented help for bare invocation and `--help`; add the
  `codex-exporter` console alias and `cdx-help`. Show effective saved defaults.
- Keep help/configuration recovery available with invalid saved settings, reject
  mixed Markdown/JSON stdout, and preserve existing files during skipped exports.

## Selector migration

Numeric user-turn indices may differ where earlier versions counted injected
service messages. Re-run `cdx-turns` before reusing old numeric selectors; native
IDs/source lines remain stable. Full source context is retained. Timestamp opt-out
removes the optional human labels, not source provenance dates.

See [storage, listings and timestamps](../LOW-DISK-EXPORTS-AND-LISTINGS.md) for
examples, exact boundaries, naming, configuration and recovery behavior. Speed and
compression ratio remain workload-dependent; a size-compliant, locally verified
ZIP does not certify a remote conversation's attachment ingestion.

## Measured packaging result

A three-repeat synthetic comparison against v0.4.0, using official 7-Zip 26.06
with the same requested LZMA settings, reduced overflowing packaging median time
from 6.2905 s to 3.7986 s (39.6%) and sampled working-disk usage by 39.8–44.1%.
Both produced four ZIPs; the new set grew by 522 bytes (0.00203%), including
metadata. The CPU-heavy ordinary single-ZIP control remained close to baseline.
Full decoding, CRC, SHA-256, contiguous coverage, and caps passed for every run.
These Linux synthetic measurements are not predictions for a particular Windows
thread. See the [benchmark methods and limits](../BENCHMARK-v0.5.0.md).
