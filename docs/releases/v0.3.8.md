# Codex Exporter v0.3.8 — Verified ZIP/LZMA archival release

**Stable release · November 2, 2026**

Codex Exporter v0.3.8 adds an automated, integrity-checked archival workflow to the existing local Codex session-to-Markdown converter. This release contains the v0.3.7 archive feature set, the v0.3.8 ZIP compression-method verification fix, and the validated PowerShell wrapper repair.

## What's new

- **One archive per export:** Create a flat, same-stem ZIP containing the rendered Markdown, its `.manifest.json`, and a byte-verified native `.jsonl` source copy. Compressed `.jsonl.zst` rollouts are decoded into the exported source copy without modifying Codex-owned files.
- **ZIP/LZMA Ultra defaults:** ZIP/LZMA, level 9, 256 MiB dictionary, 64-word setting, and up to 19 requested threads through a detected or explicitly selected 7-Zip-compatible command-line archiver.
- **Verifiable integrity and safe cleanup:** Decode and SHA-256-check every archived member against its loose original, enforce distinct flat member names and valid ZIP methods, prohibit encryption, and only clean up the exported loose files after verification. Preserve app-owned rollout JSONLs and SQLite data.
- **Compatible Store fallback:** Permit ZIP method 0 (Store) for small or incompressible members alongside LZMA method 14; reject substantive all-Store archives when LZMA was requested.
- **Configurable defaults and switches:** Use `--no-archive`, `--no-source-copy`, `--no-archive-cleanup`, `--archiver-path`, and compression overrides. View or change persisted defaults using `--show-archive-config` and `--set-archive-default`.
- **Windows PowerShell wrappers fixed:** The archive-aware `cdx-*` helper functions correctly forward individual archive switches without the dictionary `.Contains()` exceptions. The dedicated installer backs up and updates the user's loader rather than replacing the complete profile.
- **Consistent packaging:** All four CLI entrypoints and both Python archive-pipeline copies are synchronized, including the bundled Codex skill.

## Install / upgrade

Requires Python 3.10+ and a 7-Zip-compatible command-line archiver to enable the default ZIP workflow.

```powershell
# From this release's extracted source directory:
py -3.13 -m pip install --upgrade ".[zstd,exact]"
codex-export --version
codex-export --show-archive-config

# Review and install wrapper overrides, if needed:
./Install-CodexExporter-ArchiveOverrides.ps1 -WhatIf
./Install-CodexExporter-ArchiveOverrides.ps1
```

A safe first check retains all intermediate files:

```powershell
codex-export --session-id YOUR_SESSION_UUID --mode thread --fast --no-archive-cleanup
```

To retain the original loose Markdown workflow:

```powershell
codex-export --session-id YOUR_SESSION_UUID --mode thread --no-archive --no-source-copy
```

**Privacy:** Native source JSONL may include sensitive local data, even when a rendered Markdown transcript appears redacted. Use `--no-source-copy` when redaction is required. The repository and release contain no private user transcripts or machine-specific configuration.

**Format compatibility:** ZIP/LZMA is method 14 and is not supported by every built-in ZIP extractor. Prefer an up-to-date 7-Zip-compatible extractor.
