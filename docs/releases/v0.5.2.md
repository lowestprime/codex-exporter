# Codex Exporter 0.5.2

## Measured encoder progress and changing ETA

Streamed archive members now recognize native 7-Zip processed-byte counters and
use the exact requested source length for progress, throughput, and ETA. Recent
measured rates adapt to changing content. Startup, stalled telemetry, input-feed
fallback, and finalization are explicit. Counted work reaching its goal does not
claim successful stage completion before the encoder, archive close, and candidate
checks finish. Buffered parsing, rendering, normalization, output counting, and
Markdown writes also expose measured work or clear activity status.

No compression codec, configured dictionary ceiling, requested thread limit,
archive cap, or raw staging policy changes are needed for the telemetry fix.

## Reliable incremental selection and source provenance

Exact indexing recognizes only newline-terminated NUL-only records as audited
source gaps. It warns, preserves original coordinates/hashes, and retains gap bytes
when included in an excerpt. Known excluded gaps remain disclosed. No missing
content is reconstructed; other malformed selection records still fail.

Response listings now share native human-turn numbering with selection. Buffered
rendering preserves distinct repeated messages and commands using source identity,
retains native provenance for supported mirrors, and matches parallel tool outputs
by call ID. Last-N plus response/turn selection uses the same native human scope;
pending turns report a clear empty-response error. Explicit zero message-range
endpoints are rejected.

Configuration-update events are recognized as metadata, and known modern actions
remain recognized under strict schema checking when a message-only view hides
them. PowerShell and Bash gain
`cdx-since-text`, `cdx-since-turn`, `cdx-since-id`, and `cdx-since-time` while keeping
the generic selector syntax.

## Remove quadratic buffered metadata work

Timestamp/model metadata now uses one transient membership index per ordered
bucket instead of searching an ever-growing list for every event. Original value
order and serialized metadata are preserved, and caches are released before
rendering. This repairs an observed scaling problem in large buffered exports.

## Validation and upgrade

Synthetic regressions cover every selection mode, source-gap inclusion/exclusion,
identity and tool-result pairing, native 7-Zip byte counters, ETA states,
finalization, subprocess failure races, and exact rendering/write fidelity. Real
7-Zip tests independently verify archive bytes. Release CI validates the supported
OS/Python matrix and distribution installation.

Upgrade both the package and shell helper files. Existing preferences remain in
effect. Read the [detailed progress and selection guide](https://github.com/lowestprime/codex-exporter/blob/v0.5.2/docs/PROGRESS-AND-SELECTION-v0.5.2.md)
and [Windows upgrade instructions](https://github.com/lowestprime/codex-exporter/blob/v0.5.2/docs/WINDOWS-UPGRADE.md).
