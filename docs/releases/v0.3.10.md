# Codex Exporter v0.3.10 — portable text review and Deflate archives

**November 6, 2026**

An archive can be valid yet unsupported by a receiving extractor. A very large
transcript can also be inconvenient to ingest as one document. Version 0.3.10
adds verified Deflate review ZIPs and retained, bounded TXT files to ordinary
local Codex file exports, while preserving the complete rendered Markdown and
the existing live-thread snapshot contract.

## Changes

- Create `<stem>.review.zip` plus a retained `<stem>.review` directory by default.
  Ordinary path output and `--open-after` prefer the review ZIP; `--json` includes
  both the review and full-archive paths. `--no-review` opts out.
- Preserve every rendered Markdown byte in chronological TXT parts, with source
  byte/line ranges, per-part and body SHA-256 hashes, and an index for exact
  reconstruction. Code, embedded payload text, long lines, CRLF, and Unicode are
  retained. Existing rendering and redaction choices remain in effect.
- Limit complete numbered TXT parts, including their headers, to 1,000,000 UTF-8
  bytes by default. `--review-chunk-bytes` accepts 4,096–1,500,000 bytes. Include a
  bounded `RECENT.txt` excerpt and a `START_HERE.txt` upload/review guide.
- Add `--review-from` for existing ZIP, Markdown, or TXT exports. Legacy ZIP/LZMA
  conversion reads only the Markdown and matching manifest, checks their CRCs,
  preserves the input, and does not open the native JSONL member.
- Default new full archives to Deflate level 6. With `backend=auto`, Python's
  built-in writer is used unless an external archiver path is configured. Add
  `--archive-backend auto/python/7zip` and the corresponding persisted setting.
  Explicit Python selection preserves but bypasses a saved external path. LZMA
  remains available with a compatible external backend.
- Verify review ZIP member methods, CRCs, and full SHA-256 hashes. Retain the TXT
  files after full-archive cleanup. Reject ambiguous/unsafe legacy ZIP inventories
  and avoid overwriting existing review outputs.
- Support verified full-archive publication on filesystems without hard links,
  and recheck loose-member signatures before cleanup. Keep the 0.3.9 fixed-prefix
  live snapshot behavior unchanged.

## Upgrade and configure

Upgrade the interpreter that already runs your exporter:

```powershell
$py = Join-Path $env:LOCALAPPDATA 'Programs\Python\Python313\python.exe'
& $py -m pip install --upgrade --no-deps 'https://github.com/lowestprime/codex-exporter/releases/download/v0.3.10/codex_exporter-0.3.10-py3-none-any.whl'
if ($LASTEXITCODE -ne 0) { throw 'Exporter upgrade failed.' }
& $py -m codex_exporter --version
```

Review companions work automatically through existing package-routed `cdx-*`
helpers. **Previously saved LZMA settings still apply to the full archive** until
you explicitly change them. For built-in Deflate level 6:

```powershell
& $py -m codex_exporter --set-archive-default method=Deflate --set-archive-default level=6 --set-archive-default backend=python
if ($LASTEXITCODE -ne 0) { throw 'Archive configuration update failed.' }
& $py -m codex_exporter --show-archive-config
```

The saved external-archiver path is retained. To use it again, select
`backend=auto` or `backend=7zip`. No profile replacement is required for existing
package-routed helpers. Standalone-script installations also need updated scripts
and package modules; see the [Windows upgrade guide](../WINDOWS-UPGRADE.md).

## Convert an existing archive

```powershell
codex-export --review-from 'C:\Exports\previous-export.zip'
# Or choose another output directory:
codex-export --review-from 'C:\Exports\previous-export.md' --out-dir 'C:\Exports\Review'
```

No Codex installation, live-session discovery, or external archiver is needed for
this conversion. If a chat cannot access a ZIP, attach the retained TXT guide,
recent excerpt, and relevant chronological parts directly. The index identifies
which history each part contains.

## Verification and limits

Synthetic regressions independently reconstruct the original Markdown and verify
size caps, UTF-8 and line boundaries, hashes, Deflate decoding, collisions,
legacy LZMA conversion without native JSONL reads, and unsafe-inventory rejection.
Existing live-source regressions continue to cover both rendering paths. The CI
matrix targets Windows/macOS/Linux on Python 3.10 and 3.13, together with package,
PowerShell, and mirrored-script checks; the release's Actions runs provide their
results.

Review fidelity is relative to the rendered Markdown. The builder does not
restore source data omitted by Codex or the original renderer, reverify native
JSONL while converting old ZIPs, or assert that a model has read all history. The
part-size cap measures UTF-8 bytes, not exact tokens. Receiving-chat upload,
retrieval, and context constraints still apply.

Deflate removes the previous default dependence on large LZMA dictionaries and
compatible external extractors. Review files add disk usage and bounded extra
passes; runtime and compression ratio depend on actual content. No universal
speedup or end-to-end ChatGPT attachment-access guarantee is claimed.
